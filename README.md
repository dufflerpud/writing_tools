# Tools for Chris Caldwell's writing
These tools allow the writer to convert XML files containing all of the information
about the story, play etc to html, pdf etc.  These tools include mechanisms
for creating packages to send off to agents/publishers and other bits and bobs
useful for maintaining writing.
